# Turner 2004 RNA parameters

`rna_turner2004.par` is a ViennaRNA-format parameter file used by DS3dRNA's restricted local RNA thermodynamic screen. DS3dRNA parses the file directly; it does not call ViennaRNA executables during sampling.

Primary parameter reference:

> David H. Mathews, Matthew D. Disney, Jessica L. Childs, Susan J. Schroeder, Michael Zuker, and Douglas H. Turner. “Incorporating chemical modification constraints into a dynamic programming algorithm for prediction of RNA secondary structure.” *Proceedings of the National Academy of Sciences* 101(19), 7287–7292 (2004). https://doi.org/10.1073/pnas.0401799101

Parameter database reference:

> Douglas H. Turner and David H. Mathews. “NNDB: the nearest neighbor parameter database for predicting stability of nucleic acid secondary structure.” *Nucleic Acids Research* 38, D280–D282 (2010). https://doi.org/10.1093/nar/gkp892

ViennaRNA software reference:

> Ronny Lorenz et al. “ViennaRNA Package 2.0.” *Algorithms for Molecular Biology* 6, 26 (2011). https://doi.org/10.1186/1748-7188-6-26
