# Optional DSSR utility

[← DS3dRNA](../README.md) · [Inputs](../docs/INPUTS.md) · [Citations](../CITATIONS.md)

DS3dRNA's default automatic secondary-structure path uses its internal coarse-grained parser. The helper `get_dbn.py` is provided for users who prefer external DBN annotations generated by DSSR.

## Obtain DSSR

DSSR is developed and licensed separately from DS3dRNA. No DSSR executable is redistributed in this repository.

To obtain the software:

1. Register an account on the [X3DNA Forum](http://forum.x3dna.org/); the download area requires a registered, signed-in user.
2. Review the current DSSR licensing information on the [official X3DNA-DSSR site](https://x3dna.org/).
3. After signing in, download the appropriate package from the [3DNA download page](http://forum.x3dna.org/downloads/3dna-download/).

The registration, license, supported platforms, and download packages are controlled by X3DNA and may change independently of DS3dRNA.

## Batch conversion

```bash
python Tool/get_dbn.py \
  --pdb_dir path/to/pdbs \
  --dssr_bin path/to/x3dna-dssr \
  --out_dbn_dir path/to/dbn_outputs
```

The wrapper recursively discovers PDB files, runs DSSR in isolated temporary directories, preserves each `dssr-2ndstrs.dbn`, records combined DSSR output in `.dssr.log` files, and appends failures to `fail_list.txt`.
